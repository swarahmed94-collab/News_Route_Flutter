News App — iOS 27 UIScene Fix
===================================
This patch is for the News_Route_Flutter project previously provided.
It changes only these two files in your EXISTING project:
  ios/Runner/Info.plist
  ios/Runner/AppDelegate.swift

Quick install on Mac (recommended):
1) Download this zip to ~/Downloads.
2) Open VS Code Terminal inside your existing News_Route_Flutter folder
   (the folder that contains pubspec.yaml).
3) Copy and run:

   unzip -o ~/Downloads/News_iOS27_UIScene_Fix.zip -d .
   flutter clean
   flutter pub get
   flutter run

Do not re-run flutter create or delete ios/Runner.xcodeproj. Keep the
native iOS project generated by Flutter on your Mac.

The patch preserves the News article open/share MethodChannel and uses
Flutter's new implicit-engine initialization lifecycle. It adds the
complete UIScene configuration required by iOS 27.

Flutter version: Flutter >= 3.41 recommended (flutter --version).
If older, run flutter upgrade first. Code was statically checked against
Flutter's published migration guide but not compiled in this environment.

Official documentation:
https://docs.flutter.dev/release/breaking-changes/uiscenedelegate
